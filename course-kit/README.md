# The course kit has moved

It now lives in the series repository, at
[PavolC/moving-parts/course-kit](https://github.com/PavolC/moving-parts/tree/main/course-kit),
with its licence travelling inside it.

This file is a signpost rather than a redirect, because the kit's own attribution
line points at this repository as the course it was extracted from. That is
still true and worth keeping, so anyone who follows it arrives here and needs
somewhere to go next.

What the kit is: the working conventions of this course with the neural networks
taken out, the process that produced them, the learner failures behind them, a
design-doc template, the shared brand layer and the slash commands. It lived here
while it was still being refined by building this course. With a second course
starting it belongs above both, so that is where it is.

The brand layer in `src/brand/` here is this course's copy of the kit's, and the
kit's is the canonical one.
